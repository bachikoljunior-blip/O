# アエテリア戦記 決定版 — Aetheria Chronicle

スマートフォンのブラウザで遊べる、**手続き生成のオープンワールド・アクションRPG**です。
依存ライブラリはゼロ。地形も、キャラクターも、効果音も、BGMも、すべてコードから生成しています。

> **▶ 遊ぶ:** https://bachikoljunior-blip.github.io/O/

---

## 特徴

### 世界
- **768×768タイル（約24,000px四方）の大陸**をシードから生成。標高・気候・湿度から
  17種のバイオーム（草原／森／暗い森／針葉樹林／雪原／ツンドラ／砂漠／サバンナ／湿地／
  岩山／霊峰／灰の荒野…）が決まります。
- **川**は山頂から最急降下で海まで流れ、**街道**はA*で地形コストを避けながら9つの集落を結び、
  川と交差する場所には橋が架かります。
- **街**は中央広場・放射状の街路・建物・農地まで自動でレイアウト。宿屋、道具屋、鍛冶屋、
  錬金術師、冒険者ギルド、神殿、城が生成されます。
- **55か所の見どころ**：祠（転移点）、ダンジョン（多層＋ボス）、野盗の野営地、遺跡、そして
  火山の火口に潜む終盤の竜。

### 戦闘
- 3段の連続攻撃、回避ローリング（無敵フレーム付き）、**盾のガードとパリィ**（構えた直後に
  受けると相手の体勢を崩す）、弓のチャージ射撃。
- 攻撃をつなぎ、完璧回避・パリィ・ブレイクを決めると **FLOW** が上昇。最大になると8秒間、
  攻撃・移動・MP回復が強化される「アエテリア・フロウ」が発動します。
- 全敵に**体勢ゲージ**を追加。絶え間なく攻めて BREAK させると、隙を作り与ダメージも上がります。
- 5種の魔法（ファイア／アイスショット／サンダー／ヒール／ゲイル）をレベルで習得し、
  4つのスロットに自由に割り当て。
- 14種の敵に個別のAI（群れで襲う狼、突進する猪、遠距離から撃つ弓兵・蜘蛛・インプ、
  硬いゴーレム、夜に湧く不死者、ボスのトロールと灰燼竜）。
- 最終ボスは扇状の炎、着弾地点が見える隕石、予告線つき突進を使い、HP半分から第二形態へ移行。
  トロールも専用の広範囲地響きを使います。すべて回避可能な予告つきです。
- ヒットストップ、画面揺れ、ノックバック、端末の振動でフィードバック。揺れは設定で軽減できます。

### 成長と探索
- レベル、装備5部位、**接頭辞・接尾辞つきの手続き生成装備**（並／上質／希少／英雄／伝説）、
  鍛冶屋での強化（+1〜）。
- 採取・採掘・調合・調理のクラフト、商店での売買。
- 全6章のメインクエストに加え、街ごとに更新される掲示板の依頼（討伐／採集／配達／探索）。
- クエスト一覧から目的を1つ選んで追跡でき、HUD・ミニマップ・大陸地図のすべてが同じ目的地を優先表示。
- 全12種の実績を収める「冒険の記録」。連続攻撃、完璧回避、探索、強化、物語完結まで進捗を保存します。
- 昼夜サイクル（1日＝13分）と天候（雨・雪・霧・火山灰）。夜は敵が強くなります。
- 霧が晴れていく大陸地図、祠と街への**ファストトラベル**、オートセーブ。

### スマホ向けの作り
- 画面左側どこでも起点になる**フローティング仮想スティック**＋右手の大きな丸ボタン。
- iPhone SE級の幅375pxでも周囲・敵・目的地を確認できる**コンパクトミニマップ**。
- 近くの敵へ自然に向き直る**照準アシスト**。設定からいつでもOFFにできます。
- メイン目標を自動解決する**方角・距離ガイド**。幅の狭い端末でも目的地を見失いません。
- 縦持ち・横持ち両対応。セーフエリア考慮。タップ／スワイプの誤爆を防ぐジェスチャ抑止。
- **フレームレートに応じて解像度を自動調整**（60fpsを保てないと段階的に下げ、余裕が出れば戻す）。
- 端末の振動、スリープ抑止（Wake Lock）、PWAとしてホーム画面に追加可能。
- **左利き操作**でアクションボタンと移動領域を左右反転。画面揺れ軽減にも対応。
- 初回読み込み後は**オフライン起動**でき、20秒ごとの自動セーブ、画面離脱・異常終了前の保護、
  破損時バックアップ復旧に対応。アプリ切替時には全入力を安全に解除するため、復帰後に移動や
  防御が押しっぱなしになることもありません。シードごとにセーブを分離するため、共有された
  `?seed=` の世界を試しても元の冒険は消えません。旧版セーブも自動移行して読み込めます。
- キーボードとゲームパッドにも対応（PCでもそのまま遊べます）。

### 音
WebAudio によるリアルタイム生成。探索／街／戦闘／夜／ダンジョン／ボスで**調・テンポ・
コード進行が切り替わる適応型BGM**と、40種以上の合成効果音。音声ファイルは1つもありません。

## 開発

ビルド不要のプレーンな ES モジュールです。静的サーバーで開くだけで動きます。

```bash
npx http-server -p 8080 -c-1
# → http://localhost:8080/
npm test
```

品質テストは、複数シードの生成、目的地解決、クエスト追跡、旧セーブ移行・破損復旧、
左右両配置のタッチ領域、完璧回避、体勢ブレイク、竜の攻撃パターン、実績、PWAオフライン資産を検証します。

`?seed=12345` を付けると任意のシードの世界を生成できます（同じシードなら必ず同じ大陸）。

### 構成

```
index.html
src/
  main.js              起動・ローディング・メインループ・解像度の自動調整
  core/     util.js    乱数・ノイズ・数学・キャンバス補助
            input.js   マルチタッチ／キーボード／ゲームパッド
            audio.js   適応型BGMと効果音の合成
  world/    worldgen.js 標高・気候・バイオーム・川・街道・街・見どころ
            runtime.js  チャンク単位のオブジェクト配置と敵のスポーン管理
            dungeon.js  ダンジョン生成（部屋＋通路＋洞窟化）
  render/   tiles.js    地形の色・陰影・ディテールの焼き込み
            props.js    樹木・岩・遺跡などのスプライト生成
            buildings.js 2.5Dの建物
            actors.js   キャラクターとモンスターの即時描画
            icons.js    アイテムアイコン
            particles.js パーティクルとダメージ表示
            renderer.js カメラ・描画順・動的ライティング・天候・ポスト処理
  game/     game.js     ゲーム全体の統括（状態・相互作用・セーブ）
            entities.js プレイヤー・敵AI・NPC・弾・ドロップ
            items.js    アイテムと装備の生成・戦利品・レシピ
            quests.js   メインクエストと自動生成のサブクエスト
            dialogue.js 会話
  ui/       ui.js       キャンバス製の軽量UIツールキット
            hud.js      HUDとタッチ操作
            menus.js    各種メニュー画面
```

すべて手書きの JavaScript で、外部ライブラリ・画像・音声ファイルは一切使用していません。
