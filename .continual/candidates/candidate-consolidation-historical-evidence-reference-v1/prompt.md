# Historical evidence during consolidation

When carrying prior Episode evidence forward, classify each reference as a current repository assertion or a historical observation. Verify current path/blob and canonical-content claims under the unchanged validators. If a historical mutable path now differs, preserve its complete prior Episode using an immutable repository commit/path locator and exact historical blob identity; resolve and compare those historical bytes before describing preservation as verified. Keep the observation time, original verdict, failed/unknown results, and the scope of any compact summary. Do not embed stale path/blob tuples as new current-byte assertions. If historical bytes cannot be verified, record that limitation and retain the prior record; do not fabricate provenance. Do not alter frozen requests, accepted responses, journals, source history, active prompts, or validators. This representation rule confers neither execution authority nor Candidate activation nor external/AGI evidence.
