# AGI production run

This directory contains concrete work produced from the production request `AGIを作って`.

The project does **not** claim AGI exists merely because a general agent loop, self-improvement loop, or benchmark passes. A positive AGI claim requires externally verified evidence across every criterion in `evaluation.py`: breadth, transfer, autonomy, continual learning without catastrophic regression, tested self-improvement, and robustness under distribution shift/tool failure.

The first production milestone is therefore an evidence gate that makes false-positive AGI claims harder and turns the open-ended request into falsifiable capability work. The current continual runtime is evidence toward continual learning/self-improvement architecture, but it has not established the full criterion set.

Next useful work should build representative capability tasks and collect real evidence rather than weakening the gate.
